  # GooseMusic Android

  An Android port of GooseMusic, built with Rust and Iced.
</div>

Search and play music from **YouTube Music** and **SoundCloud**, with audio playback and background caching.

## Credits

Based on the original [GooseOb Music Player](https://github.com/GooseOb/music_plr). Full credit to GooseOb for the original project and app icon.
